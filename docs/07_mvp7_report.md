# 7차 MVP — 통합 시스템 + 메타 교훈

> 1~6차 MVP의 모든 발견을 통합한 production-grade 시스템 구현.
> **충격적이지만 정직한 결과**: 가장 정교한 시스템이 가장 큰 손실.

## 1. 실험 설계 — 4-way 비교

| # | 방식 | 1~6차 중 어디 적용 |
|---|---|---|
| (a) | 단일 페어 (GDX~KO만) | 1차 MVP 방식 |
| (b) | 고정 페어 풀 (7개 균등) | 2차 MVP 방식 확장 |
| (c) | 롤링 풀 + 균등 배분 | 6차 MVP 확장 |
| (d) | 롤링 풀 + 포트폴리오 켈리 | **완전 통합 (1~6차 다)** |

가설:
> "정교할수록 더 좋아야 한다 — (a) < (b) < (c) < (d)"

## 2. 결과 — 정확히 반대로

| 방식 | 최종 자본 | 수익률 | Sharpe | MDD |
|---|---|---|---|---|
| (a) 단일 GDX~KO | $104,054 | +4.05% | +0.49 | -6.47% |
| **(b) 고정 풀 7개** | **$102,945** | +2.94% | **+0.83** | **-2.20%** |
| (c) 롤링 + 균등 | $82,197 | -17.80% | -0.70 | -22.81% |
| **(d) 완전 통합** | **$79,138** | **-20.86%** | **-1.14** | -22.11% |

**(b) 고정 풀이 Sharpe 0.83으로 최고. (d) 완전 통합이 -21% 손실로 최악.**

## 3. 왜 정교한 시스템이 실패했나

차트 (`mvp7_production_comparison.png`)에서 명확히 보이는 3가지 원인:

### 원인 1: 거래 비용 누적
- 매월 페어 풀 50% 회전 (6차 MVP 결과)
- 각 페어 교체 = 청산 + 신규 진입 = 4번 체결
- 왕복 수수료 0.16% × 매월 = 연 약 2% 비용

### 원인 2: 신호 분산
- 매월 평균 8.8개 페어 동시 운용
- 각 페어 비중 1.1%만 할당
- 작은 비중에서의 거래 비용 비율이 상대적으로 큼 → 신호 위에 비용 손실

### 원인 3: 켈리 추정 노이즈
- 90일 lookback으로 mu, cov 추정
- 페어 풀이 매월 바뀌니 안정적 통계 불가능
- 가중치 변동 심해 추가 거래 발생

## 5. 1~7차를 관통하는 진짜 메타 교훈

각 MVP가 답한 질문과 답:

| MVP | 질문 | 답 |
|---|---|---|
| 1차 | 페어 트레이딩이 작동하는가? | 미확정 |
| 2차 | 단일 split이 신뢰할 만한가? | 아님 |
| 3차 | 통계가 진짜 신호인가? | 부분적 |
| 4차 | 베타가 변하는 페어는? | Kalman은 보험 |
| 5차 | 두 베타를 합치면? | 안정성↑ 수익↓ |
| 6차 | 페어는 영구한가? | 아님 (50% 회전) |
| **7차** | **정교한 통합이 답인가?** | **아니다. 단순함이 답이다.** |

> **"정교함이 수익을 보장하지 않는다. 거래 비용을 줄이는 단순함이 진짜 우위다."**

이게 1~7차 MVP의 진짜 최종 교훈. 명세서 v2가 다 옳았는데, 그 정교한 도구들을 **다 쓰면** 비용에 잡아먹힌다는 역설.

### 상단: Equity Curves (가장 중요)
- 회색 (a) 단일: 작은 수익, 안정적

**시각적으로 명백**: 시간이 지날수록 정교한 시스템 손실 폭 커짐.

### 중앙 좌: 매월 운용 페어 수
- 4~15개 변동 (6차 MVP 데이터와 동일)
- 변동성이 큼 = 신호의 일관성 부족

### 중앙 우: Per-pair PnL
- Top 10: 작지만 안정적 수익 (+$300~+$3,335)
- Bottom 5: 큰 손실 (-$2K~-$4K)
- **소수의 악성 페어가 전체를 결정**

### 하단 좌: Drawdown 비교
- (a), (b): -2~-7% 작은 drawdown
- (c), (d): -20%+ 큰 drawdown

## 7. 실전 권장

| 자본 규모 | 권장 방식 | 이유 |
|---|---|---|
| 소액 (< $10K) | **(a) 단일 페어** | 거래 비용 최소화 |
| 중간 ($10K~$100K) | **(b) 고정 풀 5~7개** | 분산 + 낮은 회전 |
| 대규모 ($100K+) | (b) + 분기별 펀더멘털 검증 | 안정 + 정기 점검 |
| 마켓메이커 / HFT | (d) 같은 정교한 시스템 | 거래 비용 극저 |

**롤링 재발굴은 마켓메이커에게만 의미**. 개인은 단순 고정 풀이 최고.

## 8. 추가 작업 후보 (실제로 의미 있는 것)

이번 결과를 보고 진짜 가치 있는 다음 단계:

### 우선순위 1: 악성 페어 차단
- AMD 관련 페어 3개가 모든 손실의 70% 차지
- **사전 필터**: backtest 결과 Sharpe 음수 페어 자동 제외
- 효과 즉시 측정 가능

### 우선순위 2: 페어 수 cap (5개로)
- 매월 4~5개만 운용 → 신호 농축
- 거래 비용 50% 절감
- 효과 즉시 측정 가능

### 우선순위 3: 진입 임계치 완화 (Z 1.5)
- entry=2.0 → 1.5로 신호 더 자주
- 단, 거래 비용 + 노이즈 증가
- 트레이드오프 측정 필요

### 우선순위 4: 거래 비용 0 가정 시뮬레이션
- 비용 0이면 (d)가 어떻게 변하는지 측정
- 거래 비용이 진짜 문제인지 확인

## 9. 명세서 v2가 옳았지만 못 본 한 가지

명세서 v2는 모든 알고리즘이 옳지만, **"비용 누적"의 영향을 알고리즘별로 측정하지 않았음**. 7차 MVP가 그 빈틈을 채움:

> "각 알고리즘은 진단 도구로는 옳지만, 모두 적용하면 비용에 망한다."

이게 7차 MVP의 진짜 기여. 이론과 실전의 격차를 정량화함.
