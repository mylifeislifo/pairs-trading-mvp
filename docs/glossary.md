# 용어집 (Glossary)

> 이 프로젝트에서 자주 쓰이는 용어를 풀어 설명합니다.

## 통계·금융 용어

### Sharpe 비율 (Sharpe ratio)
수익이 얼마나 안정적인지 측정하는 점수.

수익 / 위험 비율 — 같은 수익이라도 변동성이 작을수록 점수가 높음.

| 점수 | 의미 |
|---|---|
| > 2 | 매우 좋음 |
| 1 ~ 2 | 괜찮음 |
| 0 ~ 1 | 평범 |
| < 0 | 손실 |

### Return (수익률)
일정 기간 동안의 누적 수익.

`+5%`면 100만원 → 105만원, `-3%`면 100만원 → 97만원.

### Spread (스프레드)
두 자산 가격 사이의 차이.

페어 트레이딩은 이 차이가 평소 값으로 "돌아오는 성질"을 활용함.

예: 펩시(PEP) 가격과 코카콜라(KO) 가격의 차이가 평소 5달러였는데 갑자기 8달러로 벌어졌다. 곧 5달러로 돌아올 것이라고 베팅.

### Z-score
"평소보다 얼마나 이상한지" 점수.

- `±2`: 평소와 다른 정도 (진입 신호)
- `±3.5`: 매우 이상함 (위험 신호, 손절)
- `0`: 정상 (청산 신호)

### 평균회귀 (Mean reversion)
"이상한 값은 평소로 돌아간다"는 성질.

페어 트레이딩의 핵심 가정. 스프레드가 평소보다 벌어졌으면 곧 좁아질 것이라고 베팅.

### Half-life (반감기)
평균회귀의 속도. 스프레드가 평균에서 벗어났을 때, **절반만큼** 돌아오는 데 걸리는 시간 (일 단위).

짧을수록 빨리 회복 = 좋은 페어. 30일 이상이면 자본이 너무 오래 묶임.

### 베타 (β)
두 자산을 한 묶음으로 만드는 비율.

GDX와 KO 페어에서 β=2.177이면 → "GDX 1주는 KO 2.177주에 해당".

| 종류 | 설명 |
|---|---|
| **정적 베타** | 항상 같은 값. 한 번 정하면 변하지 않음 |
| **동적 베타** | 시간에 따라 변함. Kalman으로 추정 |

### Regime change (국면 전환)
시장 상태 자체가 바뀌는 사건.

평소 두 자산이 같이 움직였는데 갑자기 따로 노는 식. 페어 트레이딩의 가장 큰 위협.

예: 2025년 7월 금값 급등으로 GDX(금광주)가 폭주, KO와 평소 관계가 깨짐.

### Drawdown (낙폭)
자본 곡선의 최고점에서 가장 떨어진 정도.

자본이 100만원 → 130만원 → 110만원이면, drawdown = -15% (130에서 110으로).

낮을수록 안정적.

## 머신러닝·검증 용어

### Fold
데이터를 N등분한 조각 중 하나.

5-fold = 데이터를 5개 시간 구간으로 나눠 각각 시험.

### Train / Test (Validation)
- **Train**: 모델을 학습시키는 데이터
- **Test/Val**: 학습한 모델을 시험하는 별도 데이터

미래 데이터로 학습하면 안 되므로 시간 순으로 분할.

### Look-ahead bias (미래 정보 누설)
백테스트에서 미래 데이터를 실수로 보고 사용하는 오류.

예: 오늘 가격을 결정하는데 내일 가격을 이미 알고 있는 식. 결과를 비현실적으로 좋게 만듦. 반드시 차단.

### Purged K-fold
시계열 데이터에서 미래 누설을 막는 검증 방법.

검증 구간 앞쪽 30일을 학습 데이터에서 제거 (purge). 시간 인접 데이터 자기상관 차단.

### Permutation Test (순열 검정)
신호가 진짜인지, 우연인지 통계적으로 검증.

원래 신호를 200번 무작위로 섞어서 (셔플), 그 분포와 비교. 실제 결과가 셔플 분포 상위 5% 안에 있으면 "통계적으로 의미 있음".

### Overfitting (과적합)
과거 데이터에만 너무 잘 맞고 미래에는 안 맞음.

특정 파라미터 조합에서만 좋은 결과 = 오버핏 신호.

## 자본 배분 용어

### Kelly Criterion (켈리 기준)
이론적으로 자본을 가장 빨리 불릴 수 있는 베팅 비율.

승률 60%, 손익비 1:1이면 → 자본의 20% 베팅.

실전에선 위험을 줄이기 위해 **Quarter Kelly** (켈리 값의 1/4)나 **Half Kelly**를 씀.

### Pairs trading (페어 트레이딩)
두 자산을 동시에 사고 팔아 시장 방향과 무관한 수익을 노리는 전략.

예: GDX 매수 + KO 매도. 두 자산이 동시 상승해도 차이만 줄어들면 수익.

## 도구·기법 용어

### Kalman Filter (칼만 필터)
노이즈 속에서 진짜 값을 추정하는 도구.

원래 미사일 추적용으로 만들어졌지만, 금융에서는 시변 베타 추정에 사용.

### ADF Test (단위근 검정)
시계열이 "정상성"이 있는지 검정.

페어 트레이딩에서는 두 자산이 각각 비정상이어야 공적분 검정 의미가 있음.

### Cointegration (공적분)
두 비정상 시계열의 선형 결합이 정상성을 띠는 관계.

페어 트레이딩의 통계적 근거. p-value < 0.05면 공적분 관계 존재.

### TLS (Total Least Squares)
두 자산 모두에 노이즈가 있을 때 헤지 비율을 추정하는 방법.

일반 OLS는 한 자산에만 노이즈가 있다고 가정해서 비대칭.

## 약어

- **MVP**: Minimum Viable Product (최소 기능 제품)
- **OOS**: Out-of-sample (학습에 안 쓴 데이터)
- **IS**: In-sample (학습에 쓴 데이터)
- **CAGR**: Compound Annual Growth Rate (연평균 성장률)
- **MDD**: Maximum Drawdown (최대 낙폭)
