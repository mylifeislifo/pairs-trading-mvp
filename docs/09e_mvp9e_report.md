# 9차 MVP-E 보고서: 장기 검증 — 9-D 결과의 완전한 붕괴 (백테스트의 본질)

## 0. 한 줄 요약

> **9-D 결과는 인공물(artifact)로 입증됐다.** 10년 데이터에서 **5개 변형 중 4개의 Sharpe 부호 반전**, 모든 변형이 **수익률 음수**. 가장 빛났던 (refresh=180, cd=30) Sharpe +0.73이 → **-0.29로 완전 반전**. 더 충격적인 것은 **(b) 자체도 +2.94% → -0.55%로 무너져** 10년 horizon에서는 *모든 변형이 음수*. 이번 검증의 진짜 결론은 "9-D가 잘못이다"가 아니라 **"3년 백테스트는 본질적으로 신뢰할 수 없다"**.

---

## 1. 실험 설계 — 9-D를 시험대에 올리기

### 검증 목표

9-D의 핵심 주장:
- (refresh=180, cd=0): Return +6.54% — (b) 능가
- (refresh=180, cd=30): Sharpe +0.73 — (b) 거의 동등
- (refresh=90, cd=30): "통계적으로 안전한 추천"

→ 이 모두 **snapshot 3개라는 표본 부족**을 안고 있던 결과.

### 검증 방법

- **데이터**: 3년 → **10년** (753일 → 2,515일, 3.3배)
- **변형 5개 + (b) 참조** 동일 조건 재실행
- **시간 분할 안정성**: 전반 5년 / 후반 5년 별도 평가
- **3년 결과 vs 10년 결과 직접 비교**: Sharpe 부호 보존 여부

→ refresh=180에서 snapshot이 3개 → **12개로 4배 증가**. 통계적 견고성 확보.

## 3. 핵심 분석 — 왜 9-D가 인공물이었나

### 3.1 9-D의 우호적 시기 (2023-2026)

9-D는 yfinance `period='3y'`로 데이터를 가져왔으므로 정확한 기간이 **2023년 5월 ~ 2026년 5월**. 이 기간의 특성:
- **금리 안정화 이후 회복 구간** (2023-2024 금리 정점 → 2025 인하 사이클)
- 페어 트레이딩에 우호적인 평균 회귀 환경
- 변동성이 적당히 있어 신호는 풍부하되 추세는 명확하지 않음

10년 데이터에는 다음이 포함됨:
- **2018 Q4 폭락** (Fed 금리 인상 충격)
- **COVID 2020년 3월 패닉**
- **2022 인플레 충격** (페어 상관관계 일제히 무너짐)

→ **9-D의 3년 기간은 "페어 트레이딩에 가장 우호적인 3년"을 우연히 뽑은 것.** 더 일반적인 시장 조건에서는 이 전략 자체가 작동하지 않는다.

### 3.2 (b)의 풀 구성 변화 — 본질적 발견

3년 train (528일)에서 발굴된 (b) 풀: **7개 페어**
10년 train (1,760일)에서 발굴된 (b) 풀: **2개 페어** (MA~V, V~WMT)

→ **train 기간이 길어질수록 안정적으로 공적분이 유지되는 페어가 급격히 줄어든다.** 6차 MVP "영구 견고 페어 = 0개" 발견의 강력한 재확인. 10년 동안 일관되게 공적분을 유지하는 페어는 거의 없고, V (Visa)가 들어간 2개만 살아남았다.

이게 (b)조차 10년에서 무너진 진짜 이유. 페어 자체가 부족하니 풀이 -0.55%로 거의 0에 머문다.

### 3.3 9-D 가설들의 운명

| 9-D 발견 | 10년 검증 결과 |
|---|---|
| ★ (b) 최초 능가 (r180,cd=0 +6.54%) | ✗ 인공물 — 10년에서 -8.27% |
| ★ Sharpe 1위 (r180,cd=30 +0.73) | ✗ 인공물 — 10년에서 -0.29 |
| 가설 ② "회전율↑가 본질적 원인" | ✗ 부분 기각 — 10년에선 refresh와 무관하게 모두 음수 |
| 가설 ①의 부호 반전 효과 | ✗ 의미 없음 — 모두 음수 영역이라 차이 무의미 |
| 9차-A의 "롤링이 -9.78%p" | △ 10년에선 모든 변형이 음수라 결론 흐려짐 |

**9-D 보고서에서 "★★ 표본 부족 경고"를 한 것이 정확했다.** 그 경고를 진지하게 받아들이고 9-E를 실행한 것이 옳은 선택이었다.

## 4. 진짜 결론 — 이번 MVP가 가르쳐 준 것

### 4.1 백테스트 신뢰성에 관한 메타 교훈

> **3년 백테스트는 본질적으로 신뢰할 수 없다.** 시장 레짐 1-2개만 포함되며, 그 레짐이 전략에 우호적이면 가짜 alpha가 나타난다. 진짜 alpha는 여러 레짐 (인플레, 디플레, 패닉, 회복, 횡보)을 다 통과해야 한다.

### 4.2 페어 트레이딩 자체에 관한 진실

> **이 universe (28종목) + 이 설계 (단순 z-score + cap+cooldown)로는 10년 horizon에서 일관 수익이 불가능하다.** 모든 변형 + (b)까지 음수. 이건 단순한 hyperparameter 문제가 아니라 더 본질적인 한계 신호다.

가능한 원인:
1. **페어 universe 너무 좁음**: 28종목 ⇒ 페어 후보 378개 ⇒ 공적분 통과 페어 매우 적음
2. **단순 z-score 신호의 한계**: 시장 충격 시 평균 회귀가 안 일어남
3. **거래비용**: 백테스트 fee 0.04% + slippage 0.05%가 10년 누적되면 큰 부담

### 4.3 9차 시리즈 전체에서 살아남은 것 / 죽은 것

| 발견 | 3년 | 10년 | 최종 평결 |
|---|---|---|---|
| 9-A: 롤링이 -9.78%p 손실 원인 | ✓ | △ | 부분 견고 (방향성은 맞으나 정량은 다름) |
| 9-A: 켈리/필터는 무해 (+0.30%p) | ✓ | ? | 검증 안 됨 (10년에서 모두 음수라 변별력 없음) |
| 9-B: cooldown 30일이 음수 PnL 차단 | ✓ | ✗ | **기각** — 10년에서 cd=0과 cd=30 둘 다 음수 |
| 9-D: (b) 능가 가능 | ✓ | ✗ | **인공물** — 10년에서 모두 (b)에 못 미침 |
| 6차: "영구 견고 페어=0개" | ✓ | ✓✓ | **강력 재확인** — 10년 train에서 2개만 |

**유일하게 살아남은 본질적 발견**: **6차의 "영구 견고 페어=0개"**.

## 5. 다음 단계 — 가능한 3가지 방향

이번 9-E가 9-D를 무너뜨림으로써, MVP 시리즈는 본질적 갈림길에 섰다.

### 5.1 방향 A: 페어 트레이딩 자체의 한계 인정 + 다른 전략으로

가설: "단순 z-score 페어 트레이딩은 백테스트 환경에서 이미 다 짜낸 alpha. 다른 정량 전략으로."

후보:
- **모멘텀** (시장 중립 long-short)
- **변동성 매도** (옵션 기반)
- **이벤트 드리븐** (어닝, 인덱스 리밸런스)
- **크립토 펀딩비 차익** (제인스트리트 알고리즘 모델 §4)

### 5.2 방향 B: 페어 트레이딩 재설계

가설: "단순 z-score가 부족한 거지 페어 트레이딩 컨셉 자체는 살아있다."

후보 개선:
- **페어 universe 확장**: 28종목 → 200~500종목 (S&P 500, ETF 포함)
- **신호 고도화**: z-score → Kalman 베타 (4차 MVP 재도전) + Mixture Density Network (제인스트리트 §4)
- **공적분 시간 가변성 추적**: 페어가 살아있는 시기만 운용 (regime detection)

### 5.3 방향 C: 워크포워드(Walk-Forward) 엄격 적용 + 메타 분석

가설: "이번 9-E도 또 다른 단일 백테스트일 뿐. 진정한 견고성은 walk-forward로만 검증 가능."

방법:
- 10년 데이터를 **rolling 2년 train + 6개월 test 윈도우**로 슬라이딩
- 각 윈도우의 Sharpe 분포 → 평균, 표준편차, 음수 윈도우 비율
- "기대 Sharpe ± 신뢰구간" 으로 결론

## 6. 권장 다음 단계

**가장 권장: 방향 C (Walk-forward 엄격 적용)** — 9-E의 메타 교훈("단일 백테스트는 신뢰 불가")의 가장 직접적인 후속 단계. 9차 시리즈 전체가 단일 backtest 함정에 빠졌을 가능성이 있으므로, 이를 walk-forward로 재평가하면 진짜 살아남은 신호가 있는지 가린다.

**그 다음 방향 B (페어 universe 확장)** — Walk-forward로 9차 결과가 일부라도 살아남으면, universe 확장으로 더 견고한 페어 풀 발굴.

**방향 A는 마지막 선택지** — 페어 트레이딩 자체를 포기하는 것은 9-E 한 번의 결과로 결정하기엔 이르다.
