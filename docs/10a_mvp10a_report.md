# 10차 MVP-A 보고서: Universe 확장(28→99) — 가설 기각, 페어 트레이딩 한계 확정

## 0. 한 줄 요약

> **Universe를 28종목 → 99종목으로 3.5배 확장했지만 alpha 발견 실패.** 평균 Sharpe -0.22 → -0.16 (미미한 +0.06 개선), 양수 비율은 **오히려 64.3% → 57.1%로 감소**, 95% CI는 [-0.65, +0.32]로 여전히 0 포함. 더 의미 있는 발견: **신호의 변동성이 커졌다** — 양수 윈도우는 더 양수(+1.48까지), 음수 윈도우는 더 음수(-1.91까지). Universe 확장이 신호 생성 능력보다 **변동성을 키우는 효과만 냈다**. **페어 트레이딩 자체의 본질적 한계 확정**.

---

## 1. 가설 + 실험 설계

### 9-C 이후 남은 질문
> "28종목 universe가 너무 작아서 안정적 공적분 페어를 못 찾는 게 아닐까? 더 큰 universe면 진짜 alpha가 발견될 수 있다."

이게 9-C에서 (b)가 64.3% 양수지만 평균 음수였던 것에 대한 가장 자연스러운 가설.

### 실험 설계

| 항목 | 9-C | 10-A |
|---|---|---|
| **종목 수** | 28 | **99** (S&P 100 상위 79 + ETF 20) |
| **페어 후보** | 378 | **4,851** (12.8배) |
| **PairsFinder** | alpha=0.10, p=0.05 | **alpha=0.05, p=0.01 (더 엄격)** |
| **운용 페어** | 모두 | **상위 20개 cap** (half-life 짧은 순) |
| Walk-forward | 14 윈도우 | 14 윈도우 (동일) |

엄격해진 임계값은 더 많은 후보에서 의미 없는 페어를 거르기 위함. cap 20개는 페어 풀이 너무 커지면 분산 효과보다 비용이 커질까봐.

### 3.2 패턴

- **부호가 같은 윈도우** (12개): 평균적으로 **음수는 더 음수, 양수는 더 양수**
- **부호가 뒤집힌 윈도우** (2개): W7 (양→음), W12 (음→양)
- **결과**: 평균은 거의 안 변했지만 **분산은 +29% 증가** (std 0.73 → 0.94)

이건 universe 확장의 가장 본질적 효과:
> **더 많은 페어를 본다고 진짜 alpha를 찾는 게 아니라, "그 시기에 우연히 좋은 페어"를 더 많이 찾고 "그 시기에 우연히 나쁜 페어"도 더 많이 찾는 것.** 운빨의 양면이 모두 증폭된다.

### 3.3 양수 비율이 오히려 감소한 이유

64.3% → 57.1% (-7.2%p). W7, W8이 0 근처에서 음수로 뒤집힌 영향. 이것도 같은 메커니즘: 28 종목에서는 그 시기 페어가 어쩌다 0 근처에 머물렀는데, 99 종목에서는 그 시기에 안 좋은 페어가 더 많아져서 명확한 음수로 빠짐.

## 5. 메타 결론 — MVP 시리즈 최종 평결 확정

### 5.1 페어 트레이딩 한계 결론 확정

10-A의 가설 기각으로 다음이 명확해졌다:

> **이 단순 z-score 페어 트레이딩 프레임워크는, universe 크기와 무관하게, 백테스트 거래비용(8 bp round-trip)을 이기는 통계적 alpha를 생성할 수 없다.** 9-C에서 28종목, 10-A에서 99종목 — 동일한 결론.

### 5.2 4가지 검증의 누적 결론

| 시리즈 | 결과 |
|---|---|
| 단일 백테스트 (9-D) | 인공물 — 단일 시점 운빨 |
| 장기 단일 (9-E) | 모든 변형 음수 |
| Walk-forward 14 윈도우 (9-C) | CI 모두 0 포함/음수 |
| **Universe 확장 + Walk-forward (10-A)** | **CI 여전히 0 포함, 신호만 양극화** |

4번의 다른 각도 검증 모두 같은 결론. **페어 트레이딩의 본질적 한계 확정**.

### 5.3 9-10차 시리즈에서 확립된 본질적 진실

1. **6차 발견 "영구 견고 페어=0개"가 페어 트레이딩의 근본 한계** — 모든 후속 시리즈의 일관된 메시지
2. **단순 신호로는 단기 백테스트의 alpha 환상이 장기/walk-forward에서 사라진다**
3. **Universe 확장은 신호 양극화만 일으킨다** — 평균 alpha 증가 ≠ universe 크기
4. **방법론적 자산**: walk-forward + 부트스트랩 CI 표준 확립

## 6. 다음 단계 — 분기점 도달

10-A에서 페어 트레이딩 본질적 한계가 확정됐으니, 더 이상 페어 트레이딩 안에서는 의미 있는 진전 어려움.

### 6.1 방향 B: 다른 정량 전략 ★ 가장 자연스러움

walk-forward + 부트스트랩 CI 표준 (9-C에서 확립)을 그대로 다른 전략에 적용:

**후보 1: 인덱스 리밸런스 이벤트 드리븐** ★ 가장 견고할 가능성
- 제인스트리트 알고리즘 §3 차용
- S&P 500 / KOSPI 200 편입 종목 시뮬레이션
- 패시브 펀드 의무 매수 흐름 선행
- 명확한 이벤트 + 명확한 청산 시점

**후보 2: 크립토 펀딩비 차익**
- 델타 뉴트럴 — 시장 방향 무관
- 24/7 거래 가능 + 데이터 풍부
- 거래비용 큰 게 단점

**후보 3: 단순 모멘텀 시장 중립 long-short**
- Cross-sectional momentum
- 상위 N개 long + 하위 N개 short
- 매월 리밸런싱
- 잘 알려진 anomaly — 백테스트 적합 강함

### 6.2 방향 C: 페어 트레이딩 신호 고도화

같은 universe (28 or 99) + 신호만 변경:

- **Kalman 동적 베타** (4차 보류) + cap+filter
- **Hurst exponent 기반 페어 선택** (평균 회귀 강한 페어만)
- **Regime detection으로 충격기 자동 중단**

가장 가능성 있는 건 regime detection. W9 (-1.91)처럼 시장 충격기에 페어가 무너지는 걸 detect해서 미리 청산.

### 6.3 권장

**방향 B-1 (인덱스 리밸런스)**가 가장 자연스러움:
- 이벤트 기반 → 신호 SNR이 훨씬 높음
- 페어 트레이딩과 완전히 다른 메커니즘 → 새로운 발견
- 데이터 가용성 (S&P 500 편입 발표일 공개)
- Walk-forward 방법론 그대로 적용 가능

방향 C는 페어 트레이딩 안에서의 마지막 시도지만, 10-A의 양극화 패턴을 보면 신호 자체가 부족한 게 본질이라 한계 명확.
