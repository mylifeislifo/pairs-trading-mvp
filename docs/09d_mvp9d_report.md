# 9차 MVP-D 보고서: Refresh × Cooldown — (b) 최초 능가, 그러나 표본 부족 경고

## 0. 한 줄 요약

> **9차 시리즈 최초로 (b) 고정 풀을 능가**. `refresh=180일 + cd=0`이 Return **+6.54%로 (b)의 +2.94%를 3.59%p 상회**, `refresh=180 + cd=30`은 **Sharpe +0.73으로 (b)의 +0.83에 가장 근접 + MDD -1.21%로 (b)보다 우수**. 그러나 refresh=180은 snapshot이 3개뿐이라 **통계적 견고성 경고**. 더 본질적 발견: **refresh와 cooldown은 같은 문제(신규 페어 적응 손실)의 다른 도구** — 한쪽만 충분히 강하게 쓰면 다른 쪽은 잉여를 넘어 alpha를 깎는다.

---

## 1. 가설 + 실험 설계

### 9차-D 두 가지 가설

**가설 ①**: 9차-B에서 발견된 "refresh_every_days=30이 cooldown granularity의 자연 단위"가 사실이면 → refresh가 늘어날수록 cd=0과 cd=30의 차이가 사라져야 한다.

**가설 ②**: 회전율 자체가 손실의 본질적 원인이면 → refresh를 늘리면 cooldown 없이도 (b)에 가까워져야 한다.

### 실험 설계

2D grid sweep:
- `refresh_every_days ∈ {30, 60, 90, 180}` (4단계)
- `pair_cooldown_days ∈ {0, 30}` (2단계)
- = **8개 변형 + (b) 참조 = 9개 백테스트**

## 3. 주요 발견 — 5가지

### 3.1 발견 ① — (b) 최초 능가 ★★★

| 기준 | (b) | (refresh=180, cd=0) | (refresh=180, cd=30) |
|---|---:|---:|---:|
| Return | +2.94% | **+6.54%** | +2.93% |
| Sharpe | +0.83 | +0.32 | **+0.73** |
| MDD | -2.20% | -7.42% | **-1.21%** |

두 변형이 각자 다른 차원에서 (b)를 능가/근접:
- **(refresh=180, cd=0)**: 절대 수익률 1위 (+3.59%p 상회), but 변동성 큼 → Sharpe 낮음
- **(refresh=180, cd=30)**: 종합적으로 (b)에 가장 근접 — Return 동등, MDD 더 좋음, Sharpe만 -0.10p 부족

9차 시리즈에서 처음으로 (b)를 진지하게 위협한 결과.

### 3.2 발견 ② — 가설 ② 강력 지지

cd=0만 보면 (cooldown 미사용):

```
refresh   30d   60d   90d   180d
Return  -6.53 -3.82 -4.27 +6.54
```

refresh 30→180으로 늘리면 **+13.07%p 개선**. cooldown 없이도 (b)를 능가.

→ **"회전율 자체가 손실의 본질적 원인"** 가설 ✓ 강력 지지. 신규 페어 적응 손실은 페어가 자주 갈아탈수록 누적된다는 9차-A의 분해 C 결과와 완벽히 일치.

### 3.3 발견 ③ — 가설 ① 부분 지지 + 더 강한 결과

가설 ①은 "refresh↑로 cooldown 효과가 사라진다"였는데, 실제 결과는 **더 강하다**:

| Refresh | cd=0 Ret | cd=30 Ret | Δ (cd 효과) |
|---:|---:|---:|---:|
| 30d | -6.53% | +0.23% | **+6.76%p** (큰 도움) |
| 60d | -3.82% | +1.62% | +5.44%p |
| 90d | -4.27% | +2.67% | +6.94%p |
| **180d** | **+6.54%** | **+2.93%** | **-3.61%p** ← 부호 반전 |

refresh가 짧을 때(30~90d) cooldown은 +5~7%p 도움이 되지만, **refresh=180에서는 cooldown이 alpha를 깎는다 (-3.61%p)**.

→ **단순히 "효과가 사라진다"가 아니라 "효과의 부호가 뒤집힌다."** Cooldown이 잡으려던 "신규 페어 음수 PnL"이 이미 refresh=180에서 사라졌고, 대신 cooldown이 남은 양수 PnL까지 잘라낸다.

### 3.4 발견 ④ — Refresh와 Cooldown은 같은 문제의 다른 도구

두 메커니즘 모두 **신규 페어 적응 손실**을 줄인다:
- **Refresh↑**: 페어 갈아타기 자체를 덜 자주 함 → 신규 진입 횟수 자체 감소
- **Cooldown↑**: 신규 페어 진입 후 N일을 운용 안 함 → 음수 PnL 구간 회피

두 도구가 서로 직교(orthogonal)하지 않다. 한쪽이 충분히 강하면 다른 쪽이 잉여를 넘어 해가 된다. (refresh=180, cd=30)에서 평균 페어 **1.0개**라는 사실이 이를 보여준다 — 사실상 페어 운용을 거의 안 함.

수학적으로 회전율 ≈ `# new entries / total period`로 정의하면:

| Refresh | CD | # new | 회전율 |
|---:|---:|---:|---:|
| 30 | 0 | 40 | 매우 높음 |
| 30 | 30 | 21 | 높음 |
| 180 | 0 | 15 | 낮음 |
| **180 | 30** | **1** | **거의 0** |

→ refresh=180 + cd=30은 "한 번 발굴 후 거의 안 바꿈" — **(b)의 동작에 가장 가까운 변형**. Sharpe +0.73이 (b)의 +0.83에 근접한 이유.

### 3.5 발견 ⑤ — Sharpe 관점에서 여전히 (b) 우위

| 변형 | Sharpe |
|---|---:|
| (b) 고정 풀 | **+0.83** ★ |
| (refresh=180, cd=30) | +0.73 (-0.10) |
| (refresh=90, cd=30) | +0.48 (-0.35) |

수익률은 (refresh=180, cd=0)이 +6.54%로 1위지만 변동성이 크다. **위험조정 수익 관점에서는 (b)가 여전히 최강**. 다만 9차 시리즈 동안 갭이 -0.79 → -0.10으로 8배 가까이 축소됐다는 점이 중요.

## 4. 표본 부족 경고 ⚠️

refresh=180일 결과는 **snapshot이 3개**뿐이다 (data 753일, lookback 365일, 365 + 3×180 ≈ 905일이지만 데이터 끝나는 시점에서 잘림):

| Refresh | # snapshots |
|---:|---:|
| 30 | 13 |
| 60 | 7 |
| 90 | 5 |
| **180** | **3** ⚠️ |

페어 풀이 1번 또는 2번만 갱신된 결과 = 사실상 거의 정적. **통계적 견고성이 매우 떨어진다.**

- (refresh=180, cd=30)은 평균 운용 페어 **1.0개** — 한 페어가 운 좋으면 +2.93%, 운 나쁘면 어떻게 되는지 모름
- 미래 데이터(out-of-sample)에서 동일 결과 보장 안 됨
- **장기 검증(5-10년 데이터) 또는 walk-forward로 재확인 필요**

이 경고는 9차-D 결과를 "운용 가능한 최적해"로 단정하지 않는 이유다. 그래도 **방향성은 명확**: 회전율을 줄이면 신규 페어 적응 손실이 줄고 (b)에 근접한다.

## 5. 9차 시리즈 통합 — A + B + D

각 단계가 누적되며 (b)와의 격차가 줄어든다:

```
                                  Return    Sharpe   MDD
(d) 7차 baseline                   -20.86%  -1.14   -22.11%   ← 최악
8차 cap=5 (신호 농축)               -6.53%  -0.45   -14.22%   ← 신호 농축 효과
9-B  cd=30 (음수 구간 차단)         +0.23%  +0.04    -6.86%   ← 양수 회복
9-D  refresh=90 + cd=30             +2.67%  +0.48    -2.97%   ← (b) 가시권
9-D  refresh=180 + cd=30            +2.93%  +0.73    -1.21%   ← (b) 거의 동등 ★
9-D  refresh=180 + cd=0             +6.54%  +0.32    -7.42%   ← (b) 수익 능가
(b)  고정 풀                        +2.94%  +0.83    -2.20%   ← Sharpe 최강
```

### 통합 결론

> **"매월 페어를 갈아타는 롤링 메커니즘은 본질적으로 손해다."** 9차-A에서 갈아타기 자체가 -9.78%p의 손실 원인임이 밝혀졌고, 9차-B에서 cooldown으로 60%를 회수했고, 9차-D에서 **refresh 자체를 늘려 (b)에 근접/능가**가 가능함이 입증됐다.
>
> 단 표본 부족 경고를 무시할 수 없다. **현재 데이터에서 통계적으로 안전한 선택은 refresh=90 + cd=30 (snapshot 5개, Sharpe +0.48, MDD -2.97%)** 정도. refresh=180 결과는 매력적이지만 더 긴 데이터에서 재검증 필수.
