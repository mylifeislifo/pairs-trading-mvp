# 9차 MVP-C 보고서: Walk-Forward 검증 — 페어 트레이딩의 통계적 사형 선고

## 0. 한 줄 요약

> **3개 변형 모두 통계적으로 alpha 없음 입증.** (b) 평균 Sharpe -0.22 (95% CI [-0.61, +0.16], 0 포함), r180,cd=30 평균 -0.22 (95% CI [-0.44, -0.03], **0 미포함 음수 alpha 명백**), r30,cd=0 평균 -0.43 (CI [-0.95, +0.08]). 9차 시리즈 내내 빛났던 **(b) 고정 풀조차 walk-forward에서는 64.3% 양수 윈도우지만 평균이 음수 + CI에 0 포함으로 통계적 alpha 부재**. 9-D의 r180,cd=30 +0.73은 **운빨로 결정적 입증** — 14개 OOS 윈도우 중 양수 단 1개(7.1%). 메타 결론: **이 universe + 단순 z-score 페어 트레이딩으로는 거래비용을 이기는 진짜 alpha를 생성할 수 없다.**

## 1. 실험 설계

### 동기 (9-E 메타 교훈)
9-E에서 9-D 결과가 인공물이라는 게 밝혀짐. 단일 백테스트의 함정. 진정한 견고성은 **여러 시기의 결과 분포**로만 확인 가능. 그게 walk-forward.

### 윈도우 설계
- **Train**: 504 거래일 (≈2년) — PairsFinder 페어 발굴용
- **Test**: 252 거래일 (≈1년) — out-of-sample 운용
- **Step**: 126 거래일 (≈6개월) — 윈도우 overlap
- 10년 데이터 → **14개 OOS 윈도우** (2018-05 ~ 2025-11)

### 검증 대상 (3개 변형)
| 변형 | 검증 가치 |
|---|---|
| **(b) Fixed pool** | 9차 시리즈 내내 최고 — walk-forward도 최고인가? |
| **r180, cd=30** | 9-D Sharpe 1위 (+0.73) — 진짜 무너지나? |
| **r30, cd=0** | 7차 baseline — 일관되게 망하나? |

### 평가 지표
- 14개 윈도우의 Sharpe/Return/MDD 분포
- 평균 ± 표준편차, 중앙값
- **양수 Sharpe 윈도우 비율** (>60-70%면 진짜 alpha 시사)
- **부트스트랩 95% 신뢰구간** (10,000 resample) — 0 포함 여부로 통계적 유의성

## 3. 핵심 발견 — 4가지

### 3.1 발견 ① — 9-D의 r180,cd=30이 사실상 "운용 안 함" 변형 ★★★

| 지표 | 값 |
|---|---:|
| 양수 Sharpe 윈도우 | **1개 / 14개 (7.1%)** |
| 평균 Sharpe | -0.22 |
| 95% CI | [-0.44, -0.03] — **0 미포함, 음수 alpha 명백** |
| Sharpe = 0 윈도우 | **5개 (=35.7%)** ← 페어 운용 자체 안 함 |

5개 윈도우(W3, W6, W9, W10, W12, W13)에서 **Sharpe 0** — cooldown이 신규 페어를 다 막아 사실상 운용 안 한 상태. 9-D에서 +0.73을 만든 유일한 윈도우 같은 시기(2024-2025 일부)가 walk-forward에서는 W11 한 번만 양수(+0.39)로 나옴.

**9-D 보고서에서 표본 부족 경고를 한 것이 정확했음.** 9-D는 14개 윈도우 중 1개를 우연히 봤을 뿐.

### 3.2 발견 ② — (b)는 양수 비율 64.3%지만 통계적 alpha 없음

(b)는 9차 시리즈 내내 "최강"이었고 walk-forward에서도 가장 가까운 신호를 보여줌:
- **양수 윈도우 64.3%** (임계값 60% 살짝 넘음)
- **중앙값 +0.09** (양수)
- **평균 -0.22** (음수) ← 음수 윈도우 폭이 큼

이 모순의 해석: **분포가 비대칭**. 양수일 때 작고(+0.5 평균), 음수일 때 크다(-1.0~-1.5 윈도우 4개). 정량적으로:
- 양수 9개 평균: +0.30
- 음수 5개 평균: **-1.13**

→ 페어 트레이딩의 **꼬리 위험 (tail risk)**. 평소엔 조용히 작은 양수, 가끔 큰 음수. 시장 충격 (COVID, 인플레)에서 페어가 한꺼번에 무너진다.

**95% CI에 0 포함** → "alpha 있다"는 결론을 통계적으로 못 내림. "alpha 없다"도 못 내림. **결정적이지 않음.**

### 3.3 발견 ③ — 시장 레짐 의존성

윈도우별 시기와 결과를 매칭:

| 시기 | 윈도우 | (b) | r30,cd=0 | 해석 |
|---|---|---|---|---|
| 2018-2019 | W0-W1 | 음수 | 음수 | Fed 금리 인상, 페어 무너짐 |
| 2019-2020 | W2-W3 | 약양수 | 음수 | COVID 직전~직격 |
| **2020-2022 회복기** | **W4-W8** | **양수** | **양수** | **페어 트레이딩 황금기** |
| 2022-2024 | W9-W13 | 혼합 | **거의 다 음수** | 인플레+금리 충격 |

→ **9-D의 3년 데이터(2023-2026)는 W11+W12+W13 부근**. 결과적으로 회복기 잔재 + 일부 좋은 시기를 골라본 셈. 더 긴 시계열에서는 충격기가 회복기를 잠식.

### 3.4 발견 ④ — 모든 변형이 분산이 크다 — "랜덤 워크" 가능성

| 변형 | Sharpe 표준편차 |
|---|---:|
| (b) | 0.73 |
| r180,cd=30 | 0.40 |
| r30,cd=0 | **0.98** |

특히 r30,cd=0의 표준편차 0.98 — 한 윈도우에서 +1.27, 다른 윈도우에서 -2.41. 같은 전략이 시기에 따라 완전히 다른 결과를 낸다.

이건 **신호 대 잡음 비(SNR)가 너무 낮다**는 정량적 증거. 제인스트리트 §2의 비유 — "금융 데이터는 100단위 중 1단위만 유효 신호" — 가 실제로 입증됨.

### 4.2 진짜 진실

> **이 universe (28종목) + 이 설계 (단순 z-score 페어 트레이딩) + 백테스트 거래비용 (8 bp round-trip)으로는 통계적으로 유의미한 양수 alpha를 생성할 수 없다.**

3개 변형 모두 평균 Sharpe 음수, 부트스트랩 CI에 0이 포함되거나 음수 영역. **3개 시리즈(단일/장기/walk-forward)의 일관된 메시지**.

### 4.3 9차 시리즈에서 진짜로 배운 것

이번 시리즈는 "수익을 못 만드는" 결론을 냈지만, **방법론적 성과**는 막대하다:

1. **단일 백테스트의 함정** 정량적 입증 (9-D → 9-E)
2. **시간 분할 안정성**의 중요성 (9-E)
3. **Walk-forward + 부트스트랩 CI**가 진정한 견고성 검증의 표준 (9-C)
4. **양수 비율이 60% 넘어도 평균이 음수면 alpha 아님** (꼬리 위험)
5. **6차의 "영구 견고 페어=0개"가 페어 트레이딩의 본질적 한계**임이 다시 확인

이 방법론은 다음 어떤 전략으로 가든 그대로 적용 가능한 자산.

## 5. 다음 단계 — MVP 분기점

페어 트레이딩 자체의 한계가 정량적으로 입증된 이상, 더 이상 hyperparameter tuning은 무의미. 다음 후보 3가지:

### 5.1 방향 A: 페어 universe 대폭 확장 ★ 가장 자연스러움

가설: "28종목으로는 안정 공적분 페어가 너무 적다. S&P 500 + ETF 200~500종목으로 확장하면 진짜 페어 풀 발굴 가능."

검증 방법:
- 종목 200-500개로 확장 (sector ETF 포함)
- 같은 walk-forward (9-C 프레임워크 그대로)
- (b) Fixed pool의 평균 Sharpe와 양수 비율이 의미 있게 개선되는가?
- 안 되면 → 페어 트레이딩 자체 한계 결론 확정

### 5.2 방향 B: 페어 트레이딩 포기 + 다른 전략

가능한 후보 (제인스트리트 통합분석 부록 기반):
- **변동성 매도** (옵션 기반 — Risk premium 수확)
- **인덱스 리밸런스 이벤트 드리븐** (S&P 500 편입/편출 선행)
- **크립토 펀딩비 차익거래** (델타 뉴트럴)
- **모멘텀 시장 중립 long-short**

각각 walk-forward로 검증해서 진짜 alpha 있는 것 발굴.

### 5.3 방향 C: 신호 자체 고도화

같은 페어 universe + 같은 walk-forward, but 신호 생성을 개선:
- **Kalman 동적 베타** (4차에서 보류된 것) 재도전
- **MDN (Mixture Density Network)** — 제인스트리트 §4 차용
- **Regime detection** — 시장 충격기에는 자동 운용 중단

---

**개인적으로 추천: 방향 A 먼저**. 페어 트레이딩에 더 큰 universe로 한 번 더 기회를 주는 게 합리적이다. 결과가 안 좋으면 그때 방향 B로 갈아탐. 방향 C는 같은 universe에서 신호만 바꾸는 거라 한계가 더 명확할 수 있음.

## 6. 부록 — Walk-forward 방법론 정리

이번 9-C에서 확립된 방법론은 향후 어떤 전략 검증에도 그대로 적용 가능:

```
1. Train/Test/Step 결정 (예: 2y/1y/0.5y)
2. 윈도우 N개 생성
3. 각 윈도우 마다:
   - Train 데이터로 파라미터 학습/페어 발굴
   - Test 데이터로 OOS 백테스트
   - 메트릭 기록
4. 분포 분석:
   - 평균, 중앙값, 표준편차
   - 양수 비율 (>60-70% 임계)
   - 부트스트랩 95% CI (>0 → 진짜 alpha)
5. 판정:
   ✓✓ 95% CI > 0 + 양수 비율 70% → 진짜 alpha
   △  CI에 0 포함 + 양수 비율 60% → 약한 신호 가능성
   ✗  CI < 0 → 명백한 음수 alpha
```

이 표준을 따르지 않은 모든 백테스트 결과는 의심해야 한다 — 그것이 9차 시리즈의 가장 큰 메타 교훈.
